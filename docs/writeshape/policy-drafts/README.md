# Policy draft review

These WriteShape-specific drafts are editorial preparation only. They deliberately remain in `docs/`, outside `beta/public` and deployment output. They do not change access, authorize public policy publishing, create seller/refund commitments or certify compliance.

Engineering facts: [policy-data-facts.md](../policy-data-facts.md). Drafts: [privacy](privacy.md), [terms](terms.md).

Before publication, resolve every bracketed decision, verify retention/deletion and the support channel, review all deployed data flows and provider practices, approve the legal/commercial wording, and deliberately publish the approved assets. Existing Fountain policy pages are not adequate substitutes.

Google's current policies require transparent disclosure of Google-data handling and an affirmative Limited Use statement for applicable Workspace scopes. The privacy draft includes proposed wording for review, not a claim that the app is approved. Sources checked 26 September 2026: [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy) and [Google Workspace user data and developer policy](https://developers.google.com/workspace/workspace-api-user-data-developer-policy).
