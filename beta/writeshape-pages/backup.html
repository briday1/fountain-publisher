WRITESHAPE

Keep a copy of your writing

Premium uses local files and your Google Drive. Premium cancellation keeps those files, your account and any existing cloud drafts. It does not start a cloud deletion deadline.

Open WriteShape

Download a local copy

  1. Open your document in WriteShape.
  2. Choose Files → Download local copy, or Save As → Local.
  3. Keep the Fountain file for a screenplay or Markdown file for a book somewhere safe. These files can be opened outside WriteShape.

Existing cloud files

If you have earlier cloud documents, choose Files → Existing cloud files. Invited testers see the WriteShape storage tab. Select files and choose Download. Check folders and Trash for work you want to keep.

Use Version history on each file to download earlier saved versions separately. Removing a storage invitation makes cloud files read-only; it does not delete them.

Google Drive

Drive access through WriteShape requires Premium. You can always use Google Drive itself to manage your files. Invited storage testers with Premium can use Copy to Google Drive to copy cloud drafts there.
