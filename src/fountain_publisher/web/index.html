      GET STARTED
      Quick start
      Write plain-text Fountain in Source. The screenplay updates as you type; edit a line directly in Screenplay when you prefer the page view. Insights tracks scenes and dialogue automatically.
      On a blank page, use the helper buttons — Add title page, Add scene, Add dialogue, and Add direction — to insert formatted Fountain snippets, or just start typing and the format follows automatically.
      1. Use Add title page (or type Title:) to set your screenplay's metadata.
      2. Start a scene with a scene heading: INT. LOCATION - DAY.
      3. Put a character cue on its own uppercase line, then write dialogue immediately below.
      4. Use PDF mode to inspect exact compiled output, then export from File.
      
            
      SYNTAX
      Fountain format
      Fountain is readable plain text. Most elements are inferred from capitalization, blank lines, and familiar screenplay conventions.
      INT. OBSERVATORY - NIGHT

      A telescope turns beneath the dome.

      MAYA
      (quietly)
      There you are.

      CUT TO:
      Scene heading
      INT., EXT., EST., INT./EXT., or I/E
      Action
      Ordinary text separated by blank lines
      Character
      An uppercase cue followed by dialogue
      Parenthetical
      A line in parentheses inside dialogue
      Transition
      An uppercase line ending in TO:
      
            
      ORGANIZE
      Title page and structure
      Title pageTitle: My Film, Credit: Written by, Author: Name, Draft date:, and Contact: at the start of the file.
      Sections# Act One; add more # characters for deeper levels.
      Synopsis= A short outline note.
      Scene numbersINT. LAB - DAY #12#.
      Page break=== on its own line.
      Notes[[Private production note]]. Notes appear as clickable orbs in Preview; right-click a preview line to add one.
      Character notesOpen Characters in Insights and select a character. Notes are stored at the end of the Fountain source.
      General notesAdd, edit, or remove document notes from the General notes section in Insights.
      Boneyard/* omitted text */.
      
            
      CONTROL
      Forced elements and formatting
      Forced scene.THE ROOFTOP
      Forced action!THIS IS ACTION
      Forced character@McCLANE
      Forced transition> SMASH CUT TO:
      Centered> THE END <
      Lyrics~ Singing in the rain
      Dual dialogueAdd ^ to the second character cue, for example JANE ^. The two adjacent dialogue blocks render concurrently side-by-side.
      Emphasis*italic*, **bold**, ***bold italic***, _underline_
      
            
      OUTPUT
      Preview and publish
      Preview mode is optimized for fast editing and source synchronization. PDF mode is the authoritative Screenplain rendering. Choose US Letter or A4 in Settings, then export PDF or Final Draft FDX from File.
      Your current workspace is continuously cached in this browser and restored when you return. This recovery draft is separate from your files: use Save or Save As when you want to write or download a .fountain file. On a shared or sensitive browser, enable Clear workspace on exit in Settings to remove the recovery draft when you disconnect GitHub or close the tab.
      Open a local file with File → Open. Save overwrites through the File System Access API when supported; otherwise the browser downloads a safe copy.
      
            
      STORY MAP
      Beat Sheet
      Choose Beat Sheet beside Source, Preview, and PDF to write the premise and arrange the story as freeform beat cards. Its Story Flow visualizes the complete sequence and marks which beats have screenplay line ranges assigned. The Beat Sheet stands alone, so you can build the entire story plan before writing any screenplay scenes. Drag cards or use their compact arrow controls to reorder them.
      Enable View → Beat guide for a Next Beat runner across the top of Preview. Write toward the displayed beat, select the matching screenplay lines in Source or Preview, then choose Assign selection & next. The assigned area is subtly shaded and the runner advances. Assignments are optional, and you can move backward or forward through beats at any time. Beat Sheet data travels with the Fountain document and is excluded from the screenplay, PDF, page count, and word count.
      
            
      VERSION CONTROL
      GitHub
      Choose File → Connect GitHub, authorize Fountain Publisher, and select the repositories it may access. The GitHub browser lists branches, folders, and Fountain files from only those repositories.
      Opening a GitHub file loads it into the editor without changing the repository until you explicitly choose Save to GitHub. Each save creates a commit with your message. Fountain Publisher includes the version of the file you opened when saving, so GitHub rejects a conflicting update instead of silently replacing somebody else's work. Disconnect from the GitHub browser whenever you want to end the session.
      Local Save and Save As remain separate. The browser recovery draft also continues to work while a GitHub file is open.

      Vim mode
      On desktop, enable Vim mode in Settings to share Normal, Insert, and Visual modes across Source and Preview. Use i, a, I, A, o, or O to enter Insert mode. Press v for character-wise Visual mode; move to extend the selection, use y to yank or d/x to delete it. Esc or Ctrl C returns to Normal mode. Use gj/gk to move through wrapped display rows and Ctrl D/Ctrl U to move by half a screen. Normal mode also supports h j k l, w, b, 0, ^, $, gg, G, x, dd, yy, p, u, and Ctrl R.
